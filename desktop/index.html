Sprite Sheet Splitter — Desktop

A lightweight, standalone desktop utility built with Python, Tkinter, and Pillow. No browser, no server, no build step.

Download (.zip)

Requirements

  • Python 3
  • Pillow (required)
  • tkinterdnd2 (optional — enables drag & drop)

Setup & run

unzip sprite-sheet-splitter-desktop.zip
cd sprite-sheet-splitter-desktop
pip install -r requirements.txt
python sprite_slicer.py

Features

  • Import via file browser or drag-and-drop
  • Four slicing methods: Rows × Columns, Fixed Sprite Size, Auto-Detect (content-based bounding boxes for varying/irregular sprite sizes), and JSON coordinate import (custom or TexturePacker-style atlases)
  • Live preview overlay on the sprite sheet
  • Sequential or row/col-based automatic naming with a custom prefix; JSON entries can supply their own name
  • Auto-created, collision-safe output folder, with optional .zip export
  • Option to skip fully transparent tiles
